# IELTS PRACTICE TOOL

Fan project / personal study tool based on IELTS Advantage methodology.

## 📌 Overview
This web app helps IELTS students practice by skill (Listening, Reading, Writing, Speaking) and target band.

## 🚀 Features
- Skill-based learning structure
- Tips inspired by IELTS Advantage
- Practice resources (official materials and examples)
- Video learning section
- Interactive mini games
- External listening practice via British Council

## 🛠 Tech Stack
- React
- TypeScript
- Vite

## 🎯 Purpose
Non-commercial educational tool designed to support IELTS preparation in a structured and interactive way.
