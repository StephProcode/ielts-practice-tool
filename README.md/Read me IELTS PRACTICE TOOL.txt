# IELTS PRACTICE TOOL

Fan-made, non-commercial personal study tool based on the IELTS Advantage methodology.

This project helps IELTS learners explore:
- Short tips by skill
- Practice resources
- Videos
- Small interactive games

It is organized by skill and target band to make study sessions easier and more focused.

## Features
- Skill filter: Speaking, Writing, Reading, Listening
- Band filter
- Tips section
- Practice resources section
- Videos section
- Games section
- Listening resources redirected to official British Council practice pages
